introduçao ao MVC

o padrao MVC (Model-View-Controller) e uma arquitetura de software utilizada no desenvolvimento de aplicaçoes para separar a lógica de negócios, a interface do usuario e o controle dos dados.

componentes do MVC

  • Model (modelo) representa os dados e a lógica de negócio da aplicaçao.
  • view (visão) - responsável pela interface com o usuario e exibição dos dados.
  • controller(controlado) - intermedeia a comunicação entre model e view.
